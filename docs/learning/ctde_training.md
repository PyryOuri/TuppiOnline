# CTDE/self-play protocol

The CTDE milestone was specified but not started because the Milestone A
imitation kill criterion fired. The optional package retains the
`CentralizedCritic` training-only module and a deployment actor with no critic
dependency.

Had the gate passed, the preregistered attempt would have used complete
matches from 0–0, terminal candidate-team win/loss reward, a shared actor for
the two candidate seats, a centralized critic, PPO/GAE with `gamma = 1`, and
three independent seeds capped at three million candidate-controlled
decisions each. Opponents would have been frozen Phase 4 policies, with later
learned snapshots admitted only as immutable population members.

Because the clone was decisively weak, running self-play would have tested a
policy that had not reproduced the target and would not have been an
interpretable CTDE improvement experiment. The conditional gate therefore
stops Phase 6 before RL. No PPO update, self-play checkpoint, opponent
snapshot, or learned search/belief coupling was created.
