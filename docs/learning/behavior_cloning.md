# Behaviour cloning milestone

The imitation target is the unchanged deterministic `partner_aware_v1` agent.
Examples are generated by deterministic stream crossplay using frozen Phase 4
policies, while the label is queried from `partner_aware_v1` on the same formal
observation. Training, validation, and held-out membership is by independent
stream identity; no stream crosses a split.

The first corpus used an explicit 20-deal generation safety cap and contained
20,769 training observations, 7,576 validation observations, and 7,061 held-
out observations. This is an imitation corpus, not a strength bank. It was
written outside the repository under the Phase 6 run directory.

The first encoder/training pass reached 82.33% held-out agreement. It omitted
declared-contract history and trick-boundary/winner markers. One corrective
encoder revision added those fields. The corrective run reached 85.27%
held-out agreement, 84.70% showing agreement, and 85.30% trick-play
agreement. Action agreement alone was not accepted as a strength result; the
bounded direct complete-match gate remained authoritative.

The corrective checkpoint was nevertheless evaluated directly in 32 new
complementary complete-match pairs against `partner_aware_v1`. It recorded
0 wins, 1 tie, and 31 losses; the candidate match-win estimate was 0.015625
with no failures or censoring. This direct result is the authoritative
Milestone A failure, not action agreement alone.

No further architecture or hyperparameter search was run. The one permitted
corrective retraining was used for the identified encoder omission.
