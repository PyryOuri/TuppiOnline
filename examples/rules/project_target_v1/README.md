# `project_target_v1` rule examples

These JSON fixtures are executable examples of the project-owner specification.
They are normative for this project and do not import or copy behavior from
`legacy_v9_unverified`.

Card codes use rank followed by suit: `H` hearts, `D` diamonds, `C` clubs, and
`S` spades. The show-action fixtures contain complete 13-card hands so that the
absence of eligible colors or ranks can be checked rather than assumed.
